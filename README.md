# Vertexa Pro

3D model viewer for Android phones and tablets. Opens OBJ, FBX, glTF/GLB, STL, PLY, DAE, 3DS, 3MF, BLEND and more — textured, solid or wireframe. Viewing only: no export or saving.

- Native C++ engine (OpenGL ES 3) with streaming loaders, so very large files open
- Assimp (BSD-3) for the extra formats
- Jetpack Compose UI with Dark, Gray and Light themes
- In-app updates from this repository's GitHub releases

Every push to `main` builds a signed APK and publishes it as a GitHub release (`VertexaPro-ARM-<version>.apk`).
